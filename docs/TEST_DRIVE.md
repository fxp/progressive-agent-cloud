# 完整流程测试说明

欢迎测试 Progressive Agent：[打开工作台](https://progressive.xiaopingfeng.com/app)，无需邀请，用 GitHub 登录，授权飞书和 Linear，再连接自己的 Agent API Key。在 Projects 选择同步来的项目，绑定有写权限、已启用 GitHub Actions 的测试仓库和 Agent，填好允许修改的文件与测试命令，并开启自动执行。授权后开一场新会议，明确说出项目名、一个小功能和验收条件，再加一条未说明规则的模糊待办。飞书妙记待办生成后，系统每 5 分钟检查一次；请在 Agent Tasks 核对项目匹配、云端开发、测试结果、草稿 PR，以及原 GitHub／Linear 需求中的回填链接。明确需求应完成交付，模糊待办应暂停并提示澄清。完成后再观察两轮检查，确认没有重复任务、PR 或回填；如有问题，请附任务链接和脱敏截图反馈，不要发送密钥或保密会议内容。

请先准备可读的 GitHub Project 或 Linear 项目，以及有可运行测试的仓库。飞书会议应属于授权账号可访问的组织，相关读取权限需要获批。每五分钟是检查间隔，开发和测试另需时间；PR 由仓库所有者审阅后决定是否合并。

会议示例：“为【项目名】的首页增加一行只读文字『流程测试已接通』，不增加按钮，不改变现有功能。另一个建议是自动整理任务，但整理规则还没确定，请先登记并等待澄清。”请结合测试仓库确认具体页面、允许修改的文件及测试命令。
